# 抢你妹18 浏览器版

适用于 Chrome 和 Microsoft Edge（Windows / macOS）。库存请求直接在 Apple 官网标签页内执行，因此会复用浏览器已经建立的官网验证会话。

内置中国大陆、香港、日本、新加坡、美国、英国和澳大利亚门店数据，支持 iPhone 18 Pro、iPhone 18 Pro Max、iPhone Duo、iPhone 16，以及 Apple Watch Series 12、SE 3 和 Ultra 4。

## 安装

1. 打开 Chrome 的 chrome://extensions，或 Edge 的 edge://extensions。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 browser-extension。
5. 点击工具栏中的“抢你妹18”图标进入配置页。

## 使用

1. 选择地区、门店、型号、容量或尺寸、颜色或款式。
2. 添加一个或多个监控任务。
3. 点击“开始监控”，扩展会打开对应地区的 Apple 商品页。
4. 如果 Apple 官网要求验证，请在该标签页手动完成一次。
5. 扩展每 30 秒通过同一官网标签页检查库存；有货时发送浏览器通知和可选的 Bark 通知。

请保持扩展创建的 Apple 标签页打开。扩展不会绕过官网验证，也不会读取密码、付款信息或其他网站数据。
